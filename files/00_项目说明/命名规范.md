# 资产命名规范

> 一句话原则：**看文件名就知道——谁的、是什么、哪一版、什么状态、什么时候。**

## 一、标准格式

```
客户代码_资产类型_描述_规格_版本_日期[_状态].扩展名
```

| 字段 | 规则 | 示例 |
|---|---|---|
| 客户代码 | 2–6 位大写拼音首字母或英文缩写；自有资产用 `ZY`（自有），通用模板用 `TY`（通用） | `HXKJ`（华夏科技）、`LSSP`（绿山食品） |
| 资产类型 | 见下方「类型代码表」，3–4 位大写 | `LOGO` `PPT` `ALB` |
| 描述 | 简短中文，2–10 字，不含空格和特殊符号 | `主标志横版` `年度汇报` |
| 规格 | 尺寸 / 色彩模式 / 比例 / 用途，多个用 `-` 连接 | `1024px` `16x9` `A4` `CMYK` `反白` |
| 版本 | `v` + 两位数字，从 `v01` 开始；小改可用 `v01-1` | `v01` `v02` `v03-1` |
| 日期 | `YYYYMMDD`，以最后修改日为准 | `20261121` |
| 状态（可选） | `草稿` / `审核` / `定稿`，见下文 | `_定稿` |

**通用禁止事项**：不用空格、不用 `最终版`、`最新`、`改1`、`final-final`、`新建文件夹`；不用 `/ \ : * ? " < > |` 等特殊字符；英文字母统一大写代码 + 小写扩展名。

## 二、资产类型代码表

| 代码 | 含义 | 常见扩展名 |
|---|---|---|
| `LOGO` | 标志 / Logo | .ai .eps .svg .png .pdf |
| `CLR` | 色彩系统 / 色卡 / 色彩令牌 | .json .ase .pdf |
| `FNT` | 字体文件 / 字体规范 | .otf .ttf .md .pdf |
| `VI` | 视觉规范手册 | .pdf .md .indd |
| `PPT` | PPT 模板 / 演示文稿 | .pptx .potx .pdf .key |
| `ALB` | 电子画册 / 数字相册 | .html .zip .pdf |
| `IMG` | 图片 / 摄影 | .jpg .png .webp .tif |
| `ICO` | 图标 | .svg .png |
| `VID` | 视频 | .mp4 .mov |
| `DOC` | 文档（需求单、方案、报价、合同） | .md .docx .pdf |
| `MKT` | 营销物料（海报、名片、易拉宝） | .psd .ai .pdf .png |

## 三、版本号规则

- 第一版对外/对内提交为 `v01`；每轮**客户修改**升一级：`v01 → v02 → v03`；
- 同一轮内部小修（错别字、对齐）用子版本：`v02-1`、`v02-2`，不必让客户感知；
- 版本号**只增不减**，旧版本不覆盖，移入 `99_归档/旧版本/`；
- 定稿后如需再改，从下一个整数版本开始（如定稿 `v03` → 再改为 `v04`）。

## 四、状态后缀

| 后缀 | 含义 | 文件所在位置 |
|---|---|---|
| `_草稿` | 制作中，未自查 | `05_客户项目/…/02_制作中` |
| `_审核` | 已自查，等待内审或客户审核 | `05_客户项目/…/03_待审核` + `06_审核与归档/待内审` 或 `待客户审核` |
| `_定稿` | 客户书面确认，不再修改 | `05_客户项目/…/04_定稿交付` + `06_审核与归档/已定稿` |

> 不写状态后缀的文件，默认视为「草稿」。

## 六、文件夹命名

| 层级 | 规则 | 示例 |
|---|---|---|
| 一级目录 | 两位序号 + 中文名 | `02_PPT模板与演示文稿` |
| 客户项目 | `客户代码_项目名称_开始年月` | `HXKJ_2027年度品牌升级_202612` |
| 归档项目 | `年份_客户代码_项目名称` | `2027_HXKJ_年度品牌升级` |
| 模板文件夹 | 下划线开头，排序置顶 | `_客户项目模板` |
