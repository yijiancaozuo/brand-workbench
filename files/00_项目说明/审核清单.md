## 一、Logo 使用
- [ ] ★ 使用的是 `01_品牌基础/Logo` 中最新定稿版本，而非网上下载或截图
- [ ] ★ Logo 未被拉伸、压扁、旋转、改色、加阴影/描边/特效
- [ ] 安全空间（留白区）≥ 规范要求（通常为标志高度的 1/2 或字母 X 的高度），周围无文字/图形侵入
- [ ] 尺寸 ≥ 最小使用尺寸（印刷 ≥ 15mm 宽，屏幕 ≥ 120px 宽，以规范为准）
- [ ] 深色背景使用反白版，浅色背景使用全彩/单色版，对比度足够
- [ ] 复杂图片背景上有足够的干净区域或衬底
- [ ] 联合品牌（Co-branding）时双方 Logo 视觉大小均衡、有分隔线

## 二、色彩
- [ ] ★ 主色 HEX/RGB 与 `色彩系统.json` 完全一致（用取色器抽查 3 处以上）
- [ ] 印刷品使用 CMYK 值，屏幕使用 RGB/HEX，未混用
- [ ] 主色 / 辅助色 / 中性色比例合理（建议 60 : 30 : 10）
- [ ] 未出现规范外的“野色”
- [ ] 正文文字与背景对比度 ≥ 4.5:1（WCAG AA）
- [ ] 图表配色按规范色序使用

## 三、字体
- [ ] ★ 使用规范指定字体（如思源黑体 / Noto Sans CJK SC），未被系统替换（导出 PDF 后检查“字体”属性）
- [ ] ★ 商用字体有授权；免费可商用字体已核实授权（思源、阿里巴巴普惠体、HarmonyOS Sans 等）
- [ ] 字号层级符合规范（标题 / 小标题 / 正文 / 注释）
- [ ] 同页字体不超过 2 种，字重不超过 3 种
- [ ] 中文标点为全角，中英文之间留空格（如适用），数字与单位规范
- [ ] 行距 1.3–1.6 倍，无孤字孤行

## 四、图片与版权
- [ ] ★ 每张图片来源可追溯：客户提供 / 自拍 / 正版图库（附授权编号）
- [ ] ★ 无网络随意下载、带水印、无授权的图片、图标、字体、音乐
- [ ] 人物肖像有肖像使用授权（尤其员工照、客户照）
- [ ] 分辨率：印刷 ≥ 300dpi；屏幕长边 ≥ 1920px，无模糊、无马赛克
- [ ] 图片调色风格统一（色温、饱和度、滤镜）
- [ ] 图片裁切合理，人物不切头、不切关节
- [ ] 视频背景音乐已获授权

## 五、版式与内容
- [ ] 所有「示例」占位文字、占位图已替换或删除（全文搜索“示例”“XXX”“占位”）
- [ ] 页边距、对齐、网格统一；元素未超出安全区
- [ ] 页码、目录与实际页面一致
- [ ] 公司名称、数据、日期、联系方式与客户提供资料核对一致
- [ ] 无错别字（建议朗读一遍或使用校对工具）
- [ ] 敏感内容合规：无“最”“第一”“顶级”等广告法极限用语（如对外宣传用途）；地图完整

## 六、文件与交付
- [ ] 文件名符合 `命名规范.md`，版本号、状态后缀正确
- [ ] 文件放在正确的阶段文件夹
- [ ] 导出格式齐全（见 `交付清单.md`），PDF 可正常打开
- [ ] PPT：字体已嵌入或已提供字体说明；动画/切换可正常播放
- [ ] 电子画册：手机 + 电脑 + 微信内置浏览器均已测试
