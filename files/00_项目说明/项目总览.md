# 品牌资产库 · 项目总览

## 一、目的

本资产库是一人公司对外提供**企业品牌服务**的工作底座，目标是：

1. **一处存放**：所有品牌资产（Logo、色彩、字体、模板、素材、客户交付物）集中管理，不再散落在微信、桌面和下载文件夹；
2. **快速复用**：PPT 模板、电子画册模板、需求单、交付清单开箱即用，新项目当天即可启动；
3. **品质可控**：统一命名、统一流程、统一审核清单，保证每次交付都专业、可追溯；
4. **可沉淀**：每个项目结束后，把可复用的版式、组件、经验沉淀回模板库，越做越快。

## 二、服务范围

| 服务 | 内容 | 主要交付物 | 对应文件夹 |
|---|---|---|---|
| ① 企业 PPT 模板与演示文稿 | 品牌母版定制、路演/招商/年会/发布会文稿制作与美化 | `.pptx` 模板、成品文稿、PDF 版 | `02_PPT模板与演示文稿` |
| ② 企业电子画册 / 数字相册 | 企业宣传册、产品画册、周年纪念册、活动相册的数字化翻页版 | HTML 翻页画册、PDF、H5 链接、二维码 | `03_电子画册` |
| ③ 品牌资产整体管理 | Logo 整理与多格式导出、色彩系统、字体规范、视觉规范手册、素材库搭建与维护 | VI 手册、色彩令牌、资产包 | `01_品牌基础` `04_素材库` |

## 四、快速上手

1. 新客户 → 复制 `05_客户项目/_客户项目模板` → 填 `需求单.md`；
2. 品牌基础不全 → 用 `01_品牌基础/视觉规范模板.md` 和 `色彩系统.json` 先帮客户梳理；
3. 做 PPT → 从 `企业通用PPT模板_v02_2.5D.pptx`（2.5D 风格）或 `v01`（扁平风格）起步，参考 `PPT制作指南.md`；
4. 做画册 → 复制 `企业电子画册模板_v02_2.5D/`（或 `v01`），参考 `电子画册制作指南.md`；
5. 所有文件按 `命名规范.md` 命名，按 `工作流程.md` 流转，交付前过一遍 `审核清单.md`。
