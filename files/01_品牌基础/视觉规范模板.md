## 3. 色彩系统

### 3.1 色值表
| 角色 | 名称 | HEX | RGB | CMYK | Pantone | 用途 |
|---|---|---|---|---|---|---|
| 品牌主色 | 墨青（示例） | `#0F4C5C` | 15, 76, 92 | 84, 17, 0, 64 | 待确认 | 标题、Logo、主要色块、封面背景 |
| 主色浅调 | 雾青（示例） | `#D9E6E8` | 217, 230, 232 | 6, 1, 0, 9 | 待确认 | 大面积浅底、卡片背景、图表次要系列 |
| 强调色 | 琥珀（示例） | `#E0A458` | 224, 164, 88 | 0, 27, 61, 12 | 待确认 | 关键数据、按钮、重点标注（每页 ≤ 1 处） |
| 中性色-深 | 墨黑（示例） | `#1E2328` | 30, 35, 40 | 25, 13, 0, 84 | 待确认 | 正文文字 |
| 中性色-中 | 石灰（示例） | `#5B6670` | 91, 102, 112 | 19, 9, 0, 56 | 待确认 | 次要文字、注释、页脚 |
| 中性色-浅 | 浅灰（示例） | `#D5D9DD` | 213, 217, 221 | 4, 2, 0, 13 | 待确认 | 分隔线、边框 |
| 背景色 | 宣纸白（示例） | `#F6F3EE` | 246, 243, 238 | 0, 1, 3, 4 | 待确认 | 页面背景 |
| 纯白 | 纯白（示例） | `#FFFFFF` | 255, 255, 255 | 0, 0, 0, 0 | 待确认 | 深色背景上的文字、卡片 |

> 注：CMYK 为 RGB 换算的参考值，**正式印刷前须以印厂打样为准**；Pantone 需用色卡比对确认。

### 3.2 使用比例
- 背景 / 中性色约 60%，主色系约 30%，强调色 ≤ 10%；
- 强调色每页仅用于 1 处最重要的信息（如核心数字）。

### 3.3 图表色序
`#0F4C5C` → `#E0A458` → `#5E8C96` → `#B7C9CC` → `#8A6A3E` → `#5B6670`

### 3.4 无障碍
正文文字与背景对比度 ≥ 4.5:1；强调色在主色上仅用于 ≥ 24px 的大字。

## 4. 字体规范

### 4.1 指定字体
| 用途 | 中文 | 英文 / 数字 | 授权 |
|---|---|---|---|
| 标题 | 【示例：思源黑体 Bold / Noto Sans CJK SC Bold】 | 【示例：同左】 | SIL OFL，免费商用 |
| 正文 | 【示例：思源黑体 Regular】 | 【示例：同左】 | SIL OFL |
| 点缀（可选） | 【示例：思源宋体 / Noto Serif CJK SC】 | — | SIL OFL |
| 系统替代字体 | 微软雅黑 / 苹方 | Arial | 仅用于客户无法安装字体时 |

### 4.2 字号层级
| 层级 | PPT（pt） | 画册 / 网页（px） | 字重 | 行距 |
|---|---|---|---|---|
| H1 封面大标题 | 40–54 | 48–64 | Bold | 1.2 |
| H2 页面标题 | 28–32 | 32–40 | Bold | 1.3 |
| H3 小标题 | 18–22 | 20–24 | Medium/Bold | 1.4 |
| 正文 | 14–16 | 15–17 | Regular | 1.6 |
| 注释 / 页脚 | 10–12 | 12–13 | Regular | 1.5 |
| 关键数字 | 48–72 | 56–96 | Bold | 1.0 |

### 4.3 排版规则
- 同一页面字体 ≤ 2 种，字重 ≤ 3 种；
- 中文使用全角标点；中英文、中文与数字之间可加半角空格；
- 标题避免超过 2 行，正文每行 ≤ 35 个汉字。

## 6. 应用示例（Do / Don't）
| ✓ 推荐（Do） | ✗ 避免（Don't） |
|---|---|
| 大面积留白，一页一个重点 | 满屏文字、堆砌信息 |
| 主色 + 中性色为主，强调色点睛 | 一页使用 5 种以上颜色 |
| 统一的图片调色 | 不同风格、不同色温的图片混用 |
| 数据用图表或大号数字呈现 | 用长段落描述数据 |
| Logo 放在固定位置（如右上角/页脚） | 每页 Logo 位置、大小不一 |
| 使用规范字体并嵌入 | 使用系统默认字体或艺术字 |
