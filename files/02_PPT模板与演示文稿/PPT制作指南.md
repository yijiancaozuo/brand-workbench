# PPT 制作指南

> 配套模板：`企业通用PPT模板_v01.pptx`（扁平版）、`企业通用PPT模板_v02_2.5D.pptx`（2.5D 版，推荐）——均为 16:9、10 页、版式与内容槽位完全一致
> 预览：`00_项目说明/预览/PPT模板_全部页面总览.png`（v01）、`PPT模板v02_2.5D_全部页面总览.png`、`PPT模板_v01对比v02_2.5D.png`

## 一、模板结构

| 页码 | 版式 | 用途 | 替换要点 |
|---|---|---|---|
| 01 | 封面 | 公司名 + 演示主题 + 汇报人/日期 | 替换 Logo 占位、主副标题 |
| 02 | 目录 | 3–6 个章节 | 章节数增减时等距排列 |
| 03 | 章节页 | 大号章节编号 + 章节名 | 复制本页作为每章开头 |
| 04 | 公司简介 | 左文右图 + 使命/愿景/价值观 | 图片 4:5 竖图 |
| 05 | 核心数据 | 4 个关键数字 | **只把最重要的 1 个**放深色卡片 |
| 06 | 产品/服务 | 3 列服务说明 + 标签 | 每列描述 ≤ 50 字 |
| 07 | 团队 | 4 人圆形头像 | 头像统一背景与构图，需肖像授权 |
| 08 | 时间线 | 5 个节点 | 最新节点用强调色 |
| 09 | 客户案例 | 左图右文：挑战 / 方案 / 成果 | 成果写具体数字 |
| 10 | 结束页 | 致谢 + 联系方式 | 与封面呼应 |

## 二、占位内容约定
- 所有占位文字都带有 **「示例」** 字样，占位图片标注「图片占位 · 示例」，右下角有琥珀色 **「示例」** 标记（形状名为 `示例标记`）；
- 交付前：全文搜索“示例”，确认全部替换；删除所有 `示例标记` 形状；
- 每页备注区已写明“示例页”提示，交付前清空备注或改为演讲稿。

## 三、配色（与 `01_品牌基础/色彩系统.json` 一致）

| 角色 | HEX | 模板中的用法 |
|---|---|---|
| 主色 · 墨青 | `#0F4C5C` | 标题、封面/章节页背景、深色卡片 |
| 主色深浅 | `#1B6B7D` / `#5E8C96` | 封面斜切色块、小标题 |
| 浅调 · 雾青 | `#D9E6E8` | 标签底色、深底上的次要文字 |
| 强调色 · 琥珀 | `#E0A458` | 关键数字、章节编号、示例标记 |
| 正文 · 墨黑 | `#1E2328` | 正文 |
| 次要 · 石灰 | `#5B6670` | 注释、页脚 |
| 背景 · 宣纸白 | `#F6F3EE` | 内容页背景 |

已写入主题色（设计 → 变体 → 颜色），换品牌时：**先改主题色，再全局检查手动指定的颜色**。

## 四、字体与字号

- 主题字体（标题 + 正文）已设为 **Noto Sans CJK SC（思源黑体）**，SIL OFL 协议可免费商用；
- 客户电脑未安装时：交付时附带字体安装包，或在 PowerPoint「选项 → 保存 → 将字体嵌入文件」（Windows 版支持）；或导出 PDF 版本；
- 如客户指定字体（如阿里巴巴普惠体、HarmonyOS Sans），统一在主题字体中替换。

| 层级 | 字号 | 字重 |
|---|---|---|
| 封面主标题 | 44pt | Bold |
| 页面标题（结论句） | 28pt | Bold |
| 小标题 | 18–22pt | Bold |
| 正文 | 14–16pt | Regular |
| 注释 / 页脚 | 10–12pt | Regular |
| 关键数字 | 48–54pt | Bold |

## 五、版式规则
1. **画布**：16:9（13.333 × 7.5 英寸），四周安全边距 0.6 英寸；
2. **标题写结论**：“复购率超过八成” 优于 “核心数据”；
3. **一页一个重点**：正文 ≤ 6 行，每行 ≤ 30 字；
4. **强调色克制**：每页只在 1 处使用琥珀色；
5. **对齐**：同类元素左对齐、等间距；使用「排列 → 对齐」而非目测；
6. **图片**：统一调色；人物照需授权；分辨率长边 ≥ 1920px；
7. **Logo**：内容页固定在右上角，封面/结束页在左上角，不随意缩放变形；
8. **动画**：仅使用“淡入”“擦除”等简洁动画，全篇不超过 2 种。

## 六、制作流程
1. 复制模板到 `05_客户项目/客户代码_项目名/02_制作中/`，按命名规范改名，如 `HXKJ_PPT_年度汇报_16x9_v01_20261121_草稿.pptx`；
2. 替换主题色、主题字体、Logo；
3. 先写大纲（每页一句结论），再选版式填充内容；
4. 自查 → 按 `00_项目说明/审核清单.md` 逐项检查；
5. 导出 PDF 发客户审核（不发可编辑源文件）；
6. 定稿后交付：`.pptx` + `.pdf` +（可选）字体包 + 使用说明。

## 七、v02 · 2.5D 版说明

**风格**：等轴测（Isometric）插画 + 叠层卡片 + 柔和投影 + 轻渐变，配色与 v01 相同（`色彩系统.json`）。

| 元素 | 做法 | 如何修改 |
|---|---|---|
| 等轴测插画（服务器、方块、平台、台阶） | 全部用 PowerPoint **原生任意多边形**绘制（矢量，可无损缩放），形状名以 `2.5D` 开头 | 选中后改填充色即可换色；每个方块由「顶面（亮）/ 左面（本色）/ 右面（暗）」3 个面组成，改色时三个面保持亮→暗关系 |
| 叠层卡片 | 主卡片 + 1–2 层向右下偏移的浅色底层（形状名 `2.5D叠层`） | 不需要时直接删除底层 |
| 柔和投影 | 形状效果 → 阴影（外部，模糊约 0.3 英寸，透明度约 80%，主色墨青） | 「设置形状格式 → 效果 → 阴影」统一调整 |
| 渐变 | 封面/章节/结束页背景、深色数据卡片使用主色系 45°–60° 渐变 | 「设置形状格式 → 填充 → 渐变」 |
| 小立方体图标 | 标题旁、Logo 占位、列表项前的品牌符号 | 可替换为客户 Logo 图形 |

**注意**
- 文字全部是独立文本框，可直接编辑；插画放在文字下层，不影响选取；
- 插画属于“示例风格”，交付前可按客户行业替换（如制造业 → 工厂/产线，金融 → 柱状图/盾牌）；
- 投影与渐变在 WPS / Keynote 中显示效果可能略有差异，交付前请在客户常用软件中打开检查；
- 每页 2.5D 主插画只放 1 个，避免喧宾夺主；强调色（琥珀）规则不变。
