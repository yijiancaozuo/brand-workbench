## 二、如何修改

### 2.1 品牌配色
打开 `index.html`，修改 `<style>` 顶部 `:root` 里的变量（与 `01_品牌基础/色彩系统.json` 对应）：
```css
--pri:#0F4C5C;   /* 主色 */
--acc:#E0A458;   /* 强调色 */
--bg:#F6F3EE;    /* 页面底色 */
```

### 2.2 文字
用任意代码编辑器（推荐 VS Code）搜索「示例」，逐处替换。每页结构用注释 `<!-- ===== 叶 N ... ===== -->` 标出。

### 2.3 图片
1. 在 `index.html` 同级新建 `images/` 文件夹，放入图片（命名见命名规范，如 `HXKJ_IMG_总部外景_1200x1600_v01_20261121.jpg`）；
2. 将占位元素
   `<div class="ph" data-ph="企业形象主图 · 示例|…" style="…"></div>`
   替换为
   `<img src="images/xxx.jpg" style="…;width:100%;object-fit:cover">`（保留原 style 中的尺寸/定位）；
3. 若需保持“单文件”交付，可把图片转为 base64 内嵌（体积会变大，建议单图 ≤ 300KB）。

| 位置 | 建议尺寸 | 格式 |
|---|---|---|
| 整页图（左页满版） | 1200 × 1600 px（3:4） | JPG / WebP，≤ 400KB |
| 半页横图 | 1200 × 900 px（4:3） | JPG / WebP |
| 产品小图 | 800 × 600 px | JPG / PNG |
| 头像 | 400 × 400 px | JPG |
| 证书 | 按原件扫描，长边 1200px | JPG |
| 二维码 | ≥ 600 × 600 px | PNG |

### 2.4 增减页面
每个 `<div class="leaf">` 是一张纸（正面 = 右页，背面 = 下一跨页的左页）。复制整个 `leaf` 即可增加 2 页，同时更新脚本中的 `NAMES` 数组（跨页名称）。

## 三、导出 PDF
- **方法 A（推荐）**：Chrome / Edge 打开 `index.html` → 打印（Ctrl/Cmd + P）→ 目标「另存为 PDF」→ 边距「无」→ 勾选「背景图形」→ 保存；模板已内置打印样式，每个跨页自动排为一页（317.5 × 211.7 mm）。
- **方法 B（命令行）**：
  ```bash
  google-chrome --headless --no-pdf-header-footer --print-to-pdf=输出.pdf index.html
  ```
- 印刷版需另行在 InDesign 中按 A4 / 出血 3mm 制作，本模板导出的 PDF 仅用于屏幕阅读与发送。

## 四、发布与分享
| 方式 | 说明 |
|---|---|
| 直接发送 | 将 `index.html`（及 `images/`）打包为 zip 发给客户，双击即可打开 |
| 静态网页托管 | 上传到对象存储（阿里云 OSS / 腾讯云 COS）或 GitHub Pages、Netlify，获得链接 |
| 二维码 | 用链接生成二维码，用于名片、展会、海报 |
| 微信内打开 | 发布前务必在微信内置浏览器测试；国内托管需注意备案 |
